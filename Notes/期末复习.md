## 简答题1- 布尔表达式化简

### 概念：

+ 最简与或式：**乘积项个数最少**，在此基础上**保证乘积项中变量最少**。
+ 标准与或式：全部由最小项构成的与或式

### 常见计算:

+ **卡诺图**
+ 常用定律
+ **两个方法交叉验证**

### 一、 核心运算律：逻辑简化的“武器库”

#### 1. 基础转换：摩根定律 (De Morgan)

这是处理“长非号”的唯一利器，**自外向里化简会比较方便**

- $\overline{A+B} = \bar{A} \cdot \bar{B}$
- $\overline{A \cdot B} = \bar{A} + \bar{B}$

#### 2. 项数压缩：包含律（冗余律/Consensus Theorem）

- **公式：** $AB + \bar{A}C + BC = AB + \bar{A}C$
- 核心特征： 1.  有两项各含有一个变量的原变量和反变量（$A$ 与 $\bar{A}$）。
  2. 第三项（$BC$）由前两项中剩下的变量组成。
  3. 结论： 这个“拼凑出来”的 $BC$ 项是多余的，可以删去。

#### 3. 变量消减：吸收律 (Absorption)

- **直接吸收：** $A + AB = A$（$A$ 的存在使得 $AB$ 毫无意义）。
- **消去因子：** $A + \bar{A}B = A + B$
- **分配律对偶形式**：$$A + BC = (A+B)(A+C)$$
  - *注：你笔记中这里写得很棒，利用 $(A+\bar{A})(A+B)$ 来拆解，这是理解这个公式最好的方式。*

------

### 二、 方法论核心：如何“凑”出简化机会？

你的笔记里提到了两种高级技巧，这体现了对逻辑函数结构的深层理解：

- **配项法：** 通过人为增加一项（如利用 $A+\bar{A}=1$）来创造出可以提取公因式或应用吸收律的条件。
- **吸收项法：** 识别出哪些项是其他项的“子集”，从而实现大面积的压缩。

**核心逻辑：** 所有的代数简化，本质上都是在寻找 **$X + \bar{X} = 1$** 或 **$X \cdot \bar{X} = 0$** 的机会。

------

### 三、 卡诺图法 (K-map)：视觉化的化简直觉

| **关键要素** | **核心逻辑与底层规律**                                       |
| ------------ | ------------------------------------------------------------ |
| **索引排列** | 必须采用 **格雷码 (Gray Code)**，即相邻格只有 **1 位** 变量不同。这是卡诺图能化简的基础。 |
| **圈组原则** | 圈的大小必须是 $2^n$（1, 2, 4, 8...）。圈越大，消去的变量越多。**四周延伸，最左面和最右面是相邻的** |
| **核心技巧** | **看变量是否“变脸”**：在一个圈内，如果一个变量同时以“原”和“反”两种形式出现，那它就是“不稳定”的，可以直接消掉。 |

## 简答题2-组合逻辑设计

### 利用MUX实现组合逻辑

+ 列出MUX的总布尔表达式 或者MUX的多路选择器
  + 能看到所有的最小项m0...ms
+ 分析逻辑函数中是**哪些最小项的和**
  + 其实就是将最小项转化为如001这样的数，其所代表的十进制数就是我要操作的$i$
+ 求出各个$D_i$ 的值或者信号
  + 最小项的$D_i$ 设为1或者C(**或者连接到额外的输入变量**) -- 
  + 其他为0
+ 注意：别忘了连接**非EN**（将0连接到上面）

如果使用**最小项 $m_i$** 来表示，MUX 的总布尔表达式如下：

$$Y = \sum_{i=0}^{2^n-1} m_i \cdot D_i$$

或者展开写成：

$$Y = m_0D_0 + m_1D_1 + m_2D_2 + \dots + m_{2^n-1}D_{2^n-1}$$

- **考点**：给你一个布尔函数 $F(A, B, C,D) = \sum m(1, 3, 5, 6)D$，让你用一个 8 选 1 MUX 实现。
- **解法**：
  1. 把变量 $A, B, C$ 接到 MUX 的选择端 $S_2, S_1, S_0$ 上。
  2. 根据函数要求的最小项编号，把对应的 $D_i$ 接高电平（1），其余接低电平（0）。
  3. 在这个例子中：$D_1, D_3, D_5, D_6 = D$，剩下的 $D_0, D_2, D_4, D_7 = 0$。
