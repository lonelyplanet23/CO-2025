## 简答题1- 布尔表达式化简

### 概念：

+ 最简与或式：**乘积项个数最少**，在此基础上**保证乘积项中变量最少**。
+ 标准与或式：全部由最小项构成的与或式

## 简答题2-组合逻辑设计

### 利用MUX实现组合逻辑

+ 列出MUX的总布尔表达式 或者MUX的多路选择器
  + 能看到所有的最小项m0...ms
+ 分析逻辑函数中是**哪些最小项的和**
  + 其实就是将最小项转化为如001这样的数，其所代表的十进制数就是我要操作的$i$
+ 求出各个$D_i$ 的值或者信号
  + 最小项的$D_i$ 设为1或者C(**或者连接到额外的输入变量**) -- 
  + 其他为0
+ 注意：别忘了连接**非EN**（将0连接到上面）

如果使用**最小项 $m_i$** 来表示，MUX 的总布尔表达式如下：

$$Y = \sum_{i=0}^{2^n-1} m_i \cdot D_i$$

或者展开写成：

$$Y = m_0D_0 + m_1D_1 + m_2D_2 + \dots + m_{2^n-1}D_{2^n-1}$$

- **考点**：给你一个布尔函数 $F(A, B, C,D) = \sum m(1, 3, 5, 6)D$，让你用一个 8 选 1 MUX 实现。
- **解法**：
  1. 把变量 $A, B, C$ 接到 MUX 的选择端 $S_2, S_1, S_0$ 上。
  2. 根据函数要求的最小项编号，把对应的 $D_i$ 接高电平（1），其余接低电平（0）。
  3. 在这个例子中：$D_1, D_3, D_5, D_6 = D$，剩下的 $D_0, D_2, D_4, D_7 = 0$。
